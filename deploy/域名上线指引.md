# 麻将账目 · 域名上线指引

> 目标：让账目在**微信里能直接点开**，并且能转发给店员。
> 结论：不用买域名、不用备案、不用从头配证书——`aiboxpro.cn` 已经在你这台服务器上跑着 HTTPS 了，加个子域名即可。

---

## 一、为什么现在微信打不开

| 你试的地址 | 微信里的表现 | 原因 |
|---|---|---|
| `http://192.168.10.217:8823`（我给你的本地地址） | 提示"无法访问此网页"或跳回搜索页 | 微信内置浏览器**平台级屏蔽局域网私有 IP**（192.168.x.x），不是配置问题 |
| `http://119.23.45.149`（服务器 IP） | 白屏 / 进度条卡死 / 无报错 | Android 12+ 系统默认禁止 http 明文请求，微信 X5 内核会**静默掐断**；且纯 IP 无备案另有风控 |

**微信里能稳稳打开的，只有「https + 域名」**。正好，你已经具备。

| 项目 | 实测结果 |

也就是说：**域名、备案、服务器、证书链路全都是现成的**，我们只需要挂一个新的子域名上去。

## 三、三步操作（约 10 分钟）

### 第 1 步 · 加一条 DNS 解析

1. 打开 **阿里云控制台** → 搜「云解析 DNS」→ 找到 `aiboxpro.cn` → 点「解析设置」
2. 点「**添加记录**」，按下表填：

| 字段 | 填什么 |
|---|---|
| 记录类型 | `A` |
| 主机记录 | `mj` |
| 解析线路 | 默认 |
| 记录值 | `119.23.45.149` |
| TTL | 10 分钟 |

3. 保存。等 1~5 分钟生效。

> 验证：手机浏览器打开 `http://mj.aiboxpro.cn`，出现宝塔的"站点未绑定"或 404 页面，就说明解析已通（这一步必然打不开内容，正常）。

### 第 2 步 · 宝塔建站 + 绑定域名 + 开 HTTPS

1. 登录宝塔面板 → 左侧「**网站**」→「**添加站点**」
   - 域名：`mj.aiboxpro.cn`
   - 根目录：用默认的 `/www/wwwroot/mj.aiboxpro.cn`（记住它）
   - PHP 版本：**纯静态**
   - 数据库：**不创建**
2. 建好后，点这个站点的「**设置**」→ 左侧「**SSL**」
   - 选「**Let's Encrypt**」→ 勾选 `mj.aiboxpro.cn` → 点「申请」（免费，90 天自动续期）
   - 申请成功后，打开「**强制 HTTPS**」开关
3. 如果 Let's Encrypt 申请失败（偶尔限流），改用「**其他证书**」：在阿里云申请一张免费 DV 证书（每年 20 张额度），把证书内容粘进去保存。

> 验证：浏览器打开 `https://mj.aiboxpro.cn`，地址栏出现**小锁**，说明 HTTPS 通了。

### 第 3 步 · 上传 v1.7 程序

1. 宝塔 → 左侧「**文件**」→ 进 `/www/wwwroot/mj.aiboxpro.cn`
2. 点「**上传**」→ 选桌面的 **`ledger-site-v1.7.zip`** → 传完右键它 →「**解压**」到当前目录
3. 解压后会出现一个 `ledger` 文件夹 → 进去 → **全选 → 剪切** → 回到上一级根目录 → **粘贴** → 提示覆盖选「全部覆盖」
4. 把空的 `ledger` 文件夹和 zip 包删掉
5. 清一下缓存（可选，保险）：站点设置 → 打开「**防跨站攻击**」保持默认、「**网站目录**」无需改动

> 根目录最后应该是这些：`index.html`、`css/`、`js/`、`assets/`、`sw.js`、`manifest.webmanifest`

## 四、验收

1. **电脑**：开 `https://mj.aiboxpro.cn` → 进「我的」页底部，应显示 **v1.7.0**
2. **微信**：把 `https://mj.aiboxpro.cn` 发给自己 → 点开，应该**直接进账本**，不再拦截
3. **手机主屏**：微信/Safari/Chrome 里「添加到主屏幕」，从此像 App 一样一点就开

⚠️ 手机如果还显示旧版，**下拉刷新两次**（PWA 是"先用旧的、后台偷偷更新"）。**千万别点"清除网站数据"**——账目存在浏览器里，清了就一起没了。

## 五、数据搬家提醒（重要）

换了网址 = **新的一本账**。数据存在浏览器本地，按网址隔离，`119.23.45.149` 上的账不会自动出现在 `mj.aiboxpro.cn`。

搬家方法：
1. 老地址 `http://119.23.45.149` → 「我的」→「导出备份」（得到 JSON 文件）
2. 新地址 `https://mj.aiboxpro.cn` → 「我的」→「导入备份」

换之前先在老地址导出一次，别直接弃用。
