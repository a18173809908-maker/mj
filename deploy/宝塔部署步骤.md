# 部署到宝塔面板（阿里云服务器 119.23.45.149）

> 部署包：`deploy/ledger-site.zip`（75KB，纯静态文件，无需 PHP/数据库）
> 目标：浏览器打开 `http://119.23.45.149` 就是往来账
> **当前部署包版本：v1.7.0**（含 密码锁 / 牌局开台·借还·收台 / 客户独立录入 / 开台瘦身 / 每人台费可不同 / 行内收台 / 上桌人数固定 3·4 人）

---

## 🚀 网站已经建好了，只想更新版本？看这里（3 步）

线上现在是 **v1.2**，要升到 v1.7 只需要覆盖文件：

1. 宝塔左侧 **文件** → 进入站点根目录 `/www/wwwroot/119.23.45.149`
2. 点 **上传** → 选 `deploy/ledger-site.zip` → 上传完在文件列表里右键它 → **解压**（解压到当前目录）
3. 解压出 `ledger` 文件夹 → 双击进去 → **全选（点顶部全选框）→ 剪切** → 点面包屑回到站点根目录 → **粘贴** → 提示覆盖时选**全部覆盖**
   （完事把空的 `ledger` 文件夹和 `ledger-site.zip` 删掉）

**验收**：手机/电脑打开 `http://119.23.45.149`，进「我的」页底部看到 **v1.7.0** 就成功了。

这一版你会明显感觉到的不一样：
- 开台的「上桌人数」**只有「3 人」「4 人」两个按钮**了，没有 1/2/5/6 那些用不上的档位，也不能手打数字
- 人数满 4 人之后再加的人（替手 / 看牌的）只记借款，**台费默认 0**，不会替你多算钱
- 客户页列表头有「**＋ 新增客户**」，可以单独录客户了
- 牌局页「**开一台**」短了很多：只有人数、台费、上桌的人；台号/日期/备注/台费怎么收都收进「**更多选项**」里了
- 上桌的人**一人一行，台费和借款分开填**，每人台费可以不一样（默认跟着上面的台费走，单独改过就不跟了）
- 打字的搜索框**点一下就上桌**，不用再「加上桌的人 → 选 → 好了」；下面还有「最近上桌」常客，一点即加
- 牌局页「正在打的台」右侧直接有「**收台**」按钮，不用先进台面

> ⚠️ 手机上如果还是旧版：**下拉刷新两次**（旧版离线缓存是"先用旧的、后台偷偷更新"，第二次打开才是新版）。
> **千万别点浏览器的"清除网站数据/清除缓存"**——那会把手机里记的账目一起清掉！刷新就够了。

## 从零开始部署（网站还没建时看这里）

## 第 0 步：放行端口（阿里云控制台，1 分钟）

1. 阿里云控制台 → 云服务器 ECS → 你的实例 → **安全组** → 配置规则
2. **添加安全组规则**：
   - 端口范围 `80/80`，授权对象 `0.0.0.0/0`（网站访问）
   - 如果宝塔面板端口（一般 8888 或随机端口）还没放行，也加一条

> 宝塔面板首页若有「放行端口」一键按钮，点它也行。

## 第 1 步：登录宝塔面板

- 阿里云控制台实例页 → **远程连接** 进服务器终端，输入：
  ```
  bt default
  ```
  会显示面板地址、账号、密码（忘了就用这个查）
- 浏览器打开面板地址登录

## 第 2 步：建站（网站 → 添加站点）

| 项目 | 填什么 |
|------|--------|
| 域名 | `119.23.45.149`（直接填 IP，宝塔认） |
| 根目录 | 默认即可（`/www/wwwroot/119.23.45.149`） |
| PHP 版本 | **纯静态** |
| 数据库 / FTP | 都不勾 |

## 第 3 步：上传并解压（文件）

1. 宝塔左侧 **文件** → 进入站点根目录（上面那个 wwwroot 路径）
2. 把目录里默认的 `index.html`、`404.html` 等**默认文件删掉**
3. 点 **上传** → 选电脑上的 `ledger-site.zip` → 上传完点右键 **解压**
4. 解压出 `ledger` 文件夹 → 进去 → **全选里面所有文件 → 剪切** → 回到站点根目录 **粘贴**
5. 删掉空的 `ledger` 文件夹和 zip 包

> 检查标准：站点根目录下直接能看到 `index.html`、`css/`、`js/`、`sw.js`、`manifest.webmanifest`、`assets/`

## 第 4 步：验证

- 电脑浏览器打开 `http://119.23.45.149` —— 应该看到「往来账」首页
- 手机浏览器打开同一地址 → 菜单 → **添加到主屏幕**

## ⚠️ 两个重要提醒

**1. 数据是各存各的（重要）**
账目存在浏览器的 localStorage 里，按"网址"隔离。如果你之前在 `mahjong-ledger-44724.app.workbuddy.host` 上记过账，**换到 IP 地址后是空账本**。迁移办法：旧网址 →「我的」→ 导出备份（json）→ 新网址 →「我的」→ 导入备份。以后就固定用 IP 这个地址记，别换来换去。

**2. HTTP 的限制**
没有域名/HTTPS 时，应用能正常记账、备份、导出，但浏览器限制下：
- 「添加到主屏幕」只是快捷方式，**不是**全屏独立 App
- 离线缓存（断网记账）不可用，断网打不开
以后买好域名（几十块一年）告诉我，宝塔申请免费 SSL 证书配一下，就能解锁完整 PWA 体验。

## 以后更新版本怎么办

代码有更新时，宝宝这边会重新打好 `ledger-site.zip`，重复第 3 步（上传 → 解压 → 覆盖）即可。**手机里已记的数据不受影响**（数据在浏览器里，不在网站文件里）。代码也同步在 GitHub：https://github.com/a18173809908-maker/mj
