> - `deploy/ledger-site.zip` —— **前端**（静态文件在 `ledger/` 下）
> - `deploy/ledger-api-node.zip` —— **Node 后端**（主用；解压出 `ledger-api-node/`，PM2 启动）

## 🚀 只想更新版本？看这里（3 步）

> **当前线上状态（2026-09-15 实测）：v1.7.0**
> 下面这套步骤留着升级 v2.0 用。

要更新版本，只需覆盖文件：

1. 宝塔左侧 **文件** → 进入站点根目录（`/www/wwwroot/mj.aiboxpro.cn`）
2. 点 **上传** → 选桌面的 `ledger-site-v2.0.zip` → 上传完在文件列表里右键它 → **解压**（解压到当前目录）
3. 解压出 `ledger` 文件夹 → 双击进去 → **全选（点顶部全选框）→ 剪切** → 点面包屑回到站点根目录 → **粘贴** → 提示覆盖时选**全部覆盖**
   （完事把空的 `ledger` 文件夹和 zip 包删掉。v2.0 起前端包**只含前端**，后端是单独的包，见上面②）

**验收**：手机/电脑打开 `https://mj.aiboxpro.cn`，进「我的」页：
- 底部显示 **v2.0.0**
- 多出一个「**云端备份**」区块

这一版你会明显感觉到的不一样：
- 「我的」页多出「**云端备份**」：状态、立即同步、**云端版本历史**（可下载 / 回滚）、下载云端备份、重新连接
- 设「进入密码」时**自动连上云端**，账目随手就备到服务器上了
- **第二台手机用同一个密码登录，看到的是同一本账**
- 记错、误删 → 「云端版本历史」翻回那一天的版本

⚠️ **装完前端还要装后端**（`api/`），否则「云端备份」会显示「云端未连接」——见 `deploy/云端部署指引.md`。

此前各版升级要点（v1.8 强制登录门禁 · v1.7 人数固定 3/4 · v1.6 开台瘦身/每人台费/行内收台 · v1.5 客户独立录入 · v1.4 牌局模型 · v1.3 密码锁）都已在线上。

> ⚠️ 手机上如果还是旧版：**下拉刷新两次**（旧版离线缓存是"先用旧的、后台偷偷更新"，第二次打开才是新版）。
> **千万别点浏览器的"清除网站数据/清除缓存"**——账目存在手机本地，清了要重新从云端拉（云端备份装好后就不怕了）。

## 从零开始部署（网站还没建时看这里）

## 第 0 步：放行端口（阿里云控制台，1 分钟）

1. 阿里云控制台 → 云服务器 ECS → 你的实例 → **安全组** → 配置规则
2. **添加安全组规则**：
   - 端口范围 `80/80`，授权对象 `0.0.0.0/0`（网站访问）
   - 如果宝塔面板端口（一般 8888 或随机端口）还没放行，也加一条

> 宝塔面板首页若有「放行端口」一键按钮，点它也行。

## 第 1 步：登录宝塔面板

- 阿里云控制台实例页 → **远程连接** 进服务器终端，输入：
  ```
  bt default
  ```
  会显示面板地址、账号、密码（忘了就用这个查）
- 浏览器打开面板地址登录

## 第 2 步：建站（网站 → 添加站点）

| 项目 | 填什么 |
|------|--------|
| 域名 | `119.23.45.149`（直接填 IP，宝塔认） |
| 根目录 | 默认即可（`/www/wwwroot/119.23.45.149`） |
| PHP 版本 | **纯静态** |
| 数据库 / FTP | 都不勾 |

## 第 3 步：上传并解压（文件）

1. 宝塔左侧 **文件** → 进入站点根目录（上面那个 wwwroot 路径）
2. 把目录里默认的 `index.html`、`404.html` 等**默认文件删掉**
3. 点 **上传** → 选电脑上的 `ledger-site.zip` → 上传完点右键 **解压**
4. 解压出 `ledger` 文件夹 → 进去 → **全选里面所有文件 → 剪切** → 回到站点根目录 **粘贴**
5. 删掉空的 `ledger` 文件夹和 zip 包

> 检查标准：站点根目录下直接能看到 `index.html`、`css/`、`js/`、`sw.js`、`manifest.webmanifest`、`assets/`

## 第 4 步：验证

- 电脑浏览器打开 `http://119.23.45.149` —— 应该看到「往来账」首页
- 手机浏览器打开同一地址 → 菜单 → **添加到主屏幕**

## ⚠️ 两个重要提醒

**1. 数据存在哪（v2.0 之后）**
账目**日常存在手机浏览器本地**（localStorage），同时**自动备份到你自己服务器**上后端的数据目录里
（Node 版默认在 `ledger-api-node/data/`；PHP 版在站点根的 `api/data/`）。
- 换手机 → 同一个「进入密码」登录就把账搬过去；
- 手机清了数据 → 「我的 → 云端备份 → 重新连接」把账拉回来；
- 记错 / 误删 → 「云端版本历史 → 恢复」翻回那一天的版本。
- 需要在电脑上存冷备份 → 把后端整个数据目录下载走即可（`daily/` 里是每天的第一个版本）。

> 老话题仍然成立：**localStorage 按网址隔离**。换网址（比如从 IP 换成域名）看到的是另一本账。
> v2.0 起有云端后，用「导入备份」或云端同步都能把账搬过去。

**2. HTTPS / 微信**
站点已上 `https://mj.aiboxpro.cn`（HTTPS 正常），所以：
- 微信里直接点开、能转发
- 可以「添加到主屏幕」当独立 App 用，支持离线打开

## 以后更新版本怎么办

代码有更新时，宝宝这边会重新打好 `ledger-site.zip`，重复「上传 → 解压 → 剪切覆盖」即可。
**手机里已记的数据、服务器上的云端账本 / 密码 / 历史版本全都不受影响**（数据和程序是分开的，覆盖前端时根本不碰后端的数据目录）。
