# 把账目存到你自己服务器（云端备份 · v2.0）—— PHP 版（备选方案）

> ⚠️ **当前主用 Node 版，请优先看 [`Node后端部署指引.md`](./Node后端部署指引.md)。**
> 这份 PHP 版留作备选：服务器上确实装了 PHP、站点也能正常切 PHP 版本时，用哪套都行
> （**接口一个字段都不差，前端一行都不用改**，同一套 116 项测试两边都过）。
> Node 版的优势是不用装 PHP、不用改站点类型、`/api/` 整段反代后 data 目录天然够不到。

> 目标：手机记的账**自动备份到你的阿里云服务器**，换手机、清缓存、手机丢了都不怕；
> 两台手机用**同一个密码**进去看到的是**同一本账**。
>
> 服务器：`119.23.45.149`（阿里云 ECS）· 宝塔面板 · 站点 `https://mj.aiboxpro.cn`
> 后端：纯 PHP（**不需要装数据库**，账本以文件形式存在站点里的 `api/data/`）
>
> 关于数据库：服务器上虽然装了 MySQL，但这套后端**故意不用它**——一本账就是一个小文件，
> 不用建库、不用填连接密码，传上去就能跑，少一环少一个出错的地方；备份就是下载文件，
> 版本历史本身就是文件快照。真要用 SQL 查账，后面可以再加，前端一行都不用改。

## 一、给站点开 PHP（约 1 分钟）

1. 宝塔面板 → 左侧「**网站**」→ 找到 `mj.aiboxpro.cn`
2. 点这一行的「**设置**」
3. 左侧第一项「**PHP 版本**」→ 下拉选 **PHP-8.0**（7.4 / 8.1 / 8.2 / 8.3 都行，最低 7.2）→ 保存
4. 如果下拉里没有 PHP 版本可选 → 说明服务器还没装 PHP：
   左侧「**软件商店**」→ 搜 `PHP` → 选 **PHP-8.0** → 点安装（1~2 分钟，装完回到第 3 步）

> 站点原本是「纯静态」，切成 PHP 后**网站照常访问**，不会影响已有内容。

---

## 二、上传后端程序（约 2 分钟）

1. 宝塔左侧「**文件**」→ 进站点根目录 `/www/wwwroot/mj.aiboxpro.cn`
2. 点上方「**上传**」→ 选桌面的 **`ledger-cloud-server-v2.0.zip`** → 上传
3. 上传完，在文件列表里**右键这个 zip → 解压**（解压到当前目录）
4. 解压后应该看到站点根目录多了一个 **`api`** 文件夹，里面是：
   `index.php` · `lib.php` · `setup.php`
   - 如果解压出来是 `api/api/…` 或者 `server/api/…`，把里面那层 **`api` 文件夹剪切到站点根目录**
   - 解压完把 zip 删掉

## 三、自检（1 分钟，很重要）

浏览器打开：

```
https://mj.aiboxpro.cn/api/setup.php
```

应该看到一页「云端后端自检」，逐项如下：

| 检查项 | 期望 |
|---|---|
| PHP 版本 | ✓ 8.0.x（可用） |
| hash / PBKDF2 | ✓ 可用 |
| JSON 扩展 | ✓ 可用 |
| api/data 可写 | ✓ 可写 |
| **能否被外网直接下载** | ✓ 已保护 |

**如果「能否被外网直接下载」是红色 ✗**，说明账本文件能被别人直接从浏览器下载走，必须处理：

> 宝塔 → 网站 → `mj.aiboxpro.cn` → 设置 → 左侧「**伪静态**」→ 把下面这一行粘进去 → 保存 → 刷新自检页复查

```nginx
location ^~ /api/data/ { deny all; return 404; }
```

- 「api/data 不可写」→ 宝塔文件里右键 `api/data` → **权限** 设为 `755`、属主选 `www`；没有这个目录就先访问一次自检页（会自动创建）。
- 「PHP 版本不可用」→ 回到第一步换 PHP 版本。

## 四、开始用（手机上）

1. 手机浏览器打开 **https://mj.aiboxpro.cn**（微信里也能直接点开，能转发）
2. 第一次会要求**设置「进入密码」**（4-6 位数字）
   - 这个密码**同时就是云端密码**，设完自动连上云端、把本机账目备份上去
   - **一定设一个记得住的**（后面讲忘了怎么办）
3. 以后打开：输密码 → 进系统，账目自动同步，不用管
4. **第二台手机**：同样打开这个网址 → 设「进入密码」时**用同一个密码** → 进去就是同一本账
   - 如果密码跟第一台不一样 → 会提示云端密码不对，到「我的 → 云端备份 → 重新连接」输正确密码即可

## 五、日常会用到的地方

**「我的」页 → 云端备份**（新增区块）

| 看到什么 | 意思 |
|---|---|
| 🟢 已同步 · 云端 v12 | 一切正常，账已经备到服务器上了 |
| 🟡 有改动待上传 | 刚记完账，4 秒内自动传，不用管 |
| 🟡 云端未连接 | 断网了，或者服务器上的后端没装好。**此时照常记账**，联网后自动补传 |
| 🟡 未登录 | 云端登录过期（90 天），点「重新连接」输一次密码 |

区块里的四个按钮：

- **立即同步** —— 手动催一下
- **云端版本历史** —— 每同步一次留一个版本（滚动保留最近 60 个 + 每天首个保留 90 天）。可以
  - **下载** 某个版本到手机（就是个能导入的备份文件）
  - **恢复** 某个版本 —— 把云端翻回那一天的样子，本机也会跟着回去
- **下载云端备份** —— 存一份 json 到手机里（换机、保险用，跟以前一样）
- **重新连接** —— 换密码或掉线时重新登录

### 万一记错了 / 清错了 / 要翻旧账

「云端版本历史」→ 找到那天的版本 → **恢复**。
恢复本身也会产生一个新版本，所以**回滚这件事本身也能再回滚**，怎么翻都不会把数据弄丢。

### 忘了密码怎么办

密码只存哈希（不可逆），找回不了。唯一办法：锁屏上点「忘记密码」→ 清空本机数据重设密码。
**但账目不会丢**——重新设完密码后，到「我的 → 云端备份 → 重新连接」用**新的云端密码**？

> ⚠️ 注意：清空本机 **不会** 改云端密码。云端密码忘了的话，需要人工处理：
> 宝塔文件里删掉 `api/data/auth.json`（**只删这一个文件，别删 data 目录**），
> 云端密码就重置了，下次打开 App 重新设一个即可，**账本数据不受影响**。

### 想临时关掉云端

目前没有「关掉」开关（改了以后又得重装）。如果只是想不用，就别点「重新连接」，本机照常记账。

## 六、数据到底存在哪（放心版）

| 位置 | 存什么 |
|---|---|
| 手机浏览器 localStorage | 日常读写用的账本（key `ledger_mahjong_v1`） |
| 手机 localStorage | 进入密码的哈希（`ledger_mahjong_lock`）、云端登录令牌（`ledger_mahjong_token`） |
| **服务器 `api/data/ledger.json`** | 云端账本本体 |
| **服务器 `api/data/history/`** | 每次同步的历史版本（最近 60 个） |
| **服务器 `api/data/daily/`** | 每天首个版本（保留 90 天） |
| 服务器 `api/data/auth.json` | 云端密码哈希 + 盐（不是明文） |

> 想在电脑上留一份冷备份：宝塔文件里把 `api/data/daily/` 里的 json 下载下来存到电脑，
> 那就是当天完整的一本账，用 App 的「导入备份」能直接吃。

## 八、出问题先看这三条

1. 手机显示「云端未连接」→ 浏览器打开 `https://mj.aiboxpro.cn/api/setup.php` 看自检页是否全绿
2. 自检页打不开（404）→ 后端没传上去，或者站点的 PHP 版本没开
3. 提示「云端已有更新的版本」→ 这是保护机制：另一台设备先改了。App 会弹窗让你选用哪一份，**两边的旧版本都还在历史里**
