# 往来账 · 麻将馆记账

给麻将馆老板用的客户往来账工具：**谁欠了钱、还了钱、还欠多少**，手机上点几下就记完。

## 怎么在安卓手机上用

1. 用手机 Chrome（或其他浏览器）打开应用网址；
2. 点浏览器菜单里的 **「添加到主屏幕」**；
3. 桌面上就会出现「往来账」图标，点开像普通 App 一样全屏使用，**断网也能用**。

## 功能一览

| 页面 | 干什么 |
|------|--------|
| 客户 | 应收总额 + 客户欠款列表（可搜索、按欠款/最近/姓名排序），点客户进详情，欠款分「借款 / 台费 / 烟钱」小计 |
| 牌局 | 开台 → 借还 → 收台一场清：上桌人数 × 每人台费（10 / 20 一键选），**开台每人先借 500（可单改、可不借）**，局中随时再借 / 还钱，收台结算；今日/本月营业额一目了然 |
| 流水 | 全部记录按日期倒序，可按「记欠款/收回」和「借款/台费/烟钱/其他」筛选、搜客户或备注 |
| 统计 | 本月营业额/收现/挂账、**本月借出/收回/净借出**、场均收入、近 6 个月营收柱状图、欠款 TOP5 |
| 我的 | 密码锁（数字密码开屏门禁）、烟品价目管理、导出备份(json)、导入备份、导出 Excel(csv)、批量导入客户名单、清空数据 |

**记一笔往来**：点右下角 <b>＋</b> → 选客户 → 选分类（台费茶水 / 代买烟 / 其他）→ 输金额 → 保存。
选「代买烟」时备注区变成烟价目表，点一下自动填金额和烟名；烟价目在「我的 → 烟品价目」里维护（默认给了几档常见价位，改成你店里常卖的名字即可）。

**一场牌的完整流程**：
1. **开台**：牌局页点「开一台」→ 台号、上桌人数（1-6 快捷）→ 每人台费（10/20/30/50）→ 台费怎么收（**单独收** / **从借款里扣**，借 500 扣 20 实拿 480）→ 「谁借钱了」加上桌的人，**每位默认借 ¥500 可单独改，不用借的记 0** → 开台；
2. **局中**：点台面，每个人旁边有「借 / 还」——输光了随时再借，赢了随时还，一个人可以好几笔，全部留痕带时间；
3. **收台**：点「收台结算」看汇总（台费收入 / 借出 / 已还 / 牌面还欠），谁要结账当场点「收款」，剩下的**继续挂在各自账上**，确认收台。

**台费 / 烟钱挂账**：开台时没收上来的台费、代买烟，会自动变成该客户的欠款，欠款明细带「牌局挂账」标记能追到是哪一场；改/删这场，挂账自动同步。

**催款**：客户详情页可一键拨打电话。

**密码锁**：「我的 → 安全 → 开启密码锁」，设 4-6 位数字密码后，打开应用要先输密码，防止别人拿到网址随手翻账。
- 支持勾选「本机记住 7 天」免重复输入；「立即锁定」可随时锁屏；
- 连续输错 3 次会显示你设置时填的**密码提示**；输错 5 次冷却 30 秒；
- 密码经过加盐多轮哈希后存储，**不存明文**；但密码只存在本机、无法找回——忘了只能「清空数据并重置密码」（有备份就能恢复）。

## 口径约定

- 每位客户一个余额：**正数 = 他欠你（红色）**，**负数 = 你多收了他的（绿色）**，0 = 已结清。
- 「记欠款」= 欠款增加；「收回欠款」= 欠款减少。支持部分还款，笔笔留痕。
- 流水可随时点开修改、删除，改完余额自动重算。
- **营业额 ≠ 现金**：营业额含挂账部分，「收现」是当场实际到手的，差额就是挂账。
- **借款不是收入**：开台借给客人的钱是往来款（欠款增加），只有台费算营业收入；客人还钱是欠款减少，也不算收入。
- 挂账的烟钱是代买垫付，**不算营业额**，只进客户欠款。

## 数据安全（重要）

- 所有数据只存在 **手机的浏览器本地**，不上传任何服务器，不联网也能用。
- ⚠️ 清浏览器数据/卸载浏览器可能丢数据。**请定期在「我的」里点「导出备份文件」**，换手机时用「导入备份」恢复。
- 同一部手机上换浏览器打开 = 两份独立数据。

## 技术备注

- 纯原生 HTML/CSS/JS 单页应用，零依赖、零构建；PWA（manifest + service worker）支持离线与主屏幕安装。
- 牌局模型：一场牌有生命周期（open/closed），场内的借款/还款/挂账全部以流水形式存储并用场次 ID 双向关联——真相只有一份，改删场次自动同步，不会两边对不上。
- 密码锁为纯前端门禁（站点无后端可挂）：SHA-256 加盐 3000 轮迭代存储于 localStorage（HTTP 下浏览器不提供 WebCrypto，故内置纯 JS 实现）。它防"随手翻看"，防不了懂技术的人直接读 localStorage——真正的敏感数据不出本机才是根基。
- 本地开发预览：在本目录起任意静态服务器（如 `python -m http.server 8823`）后访问。
- 图标由 `tools/make_icons.py` 生成（纯标准库，无 Pillow 依赖）。
