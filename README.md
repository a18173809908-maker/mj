# 往来账 · 麻将馆记账

给麻将馆老板用的客户往来账工具：**谁欠了钱、还了钱、还欠多少**，手机上点几下就记完。

## 怎么在安卓手机上用

1. 用手机 Chrome（或其他浏览器）打开应用网址；
2. 点浏览器菜单里的 **「添加到主屏幕」**；
3. 桌面上就会出现「往来账」图标，点开像普通 App 一样全屏使用，**断网也能用**。

## 功能一览

| 页面 | 干什么 |
|------|--------|
| 客户 | 应收总额 + 客户欠款列表（可搜索、按欠款/最近/姓名排序），**「＋ 新增客户」单独录人不记账也能建**，点客户进详情，欠款分「借款 / 台费 / 烟钱」小计 |
| 牌局 | 开台 → 借还 → 收台一场清：开台只需选**人数（只有 3 人 / 4 人）** + 台费，**台费每人可不同**，**开台每人先借 500（可单改、可不借）**，局中随时再借 / 还钱，列表上直接「收台」结算；今日/本月营业额一目了然 |
| 流水 | 全部记录按日期倒序，可按「记欠款/收回」和「借款/台费/烟钱/其他」筛选、搜客户或备注 |
| 统计 | 本月营业额/收现/挂账、**本月借出/收回/净借出**、场均收入、近 6 个月营收柱状图、欠款 TOP5 |
| 我的 | 登录门禁（**强制**）、**云端备份（存到自己的服务器，多设备同一本账 + 版本回滚）**、烟品价目管理、导出备份(json)、导入备份、导出 Excel(csv)、批量导入客户名单、清空数据 |

**新增客户（单独录入，不用先记账）**：客户页点列表右上「<b>＋ 新增客户</b>」（或顶栏人形+图标、「我的 → 客户名单 → 新增客户」）→ 填姓名 / 电话 / 备注 → 保存。
- 「<b>存下再录一位</b>」可以一口气把常来的客人们都建好，录完不关抽屉接着录；
- 「<b>保存并查看</b>」存完直接进这位客户的详情页，马上就能记欠款 / 收款。

**记一笔往来**：点右下角 <b>＋</b> → 选客户 → 选分类（台费茶水 / 代买烟 / 其他）→ 输金额 → 保存。
选「代买烟」时备注区变成烟价目表，点一下自动填金额和烟名；烟价目在「我的 → 烟品价目」里维护（默认给了几档常见价位，改成你店里常卖的名字即可）。

**一场牌的完整流程**：
1. **开台**：牌局页点「开一台」→ **上桌人数只有「3 人」「4 人」两个按钮**（一场牌就这两种，没有别的档位）+ 台费（10/20/30/50 一键选）。要记人就打字搜客户、**点一下就上桌**（或点下面「最近上桌」的常客），**一人一行：台费 + 借款分开填，每人台费可以不一样**（没单独改过的跟着上面的台费走），借款默认 ¥500、不用借的记 0。台号 / 日期 / 备注 / 台费怎么收（单独收 / 从借款里扣，借 500 扣 20 实拿 480）都收在「**更多选项**」里，日常不用管 → 开台；
2. **局中**：点台面，每个人旁边有「借 / 还」——输光了随时再借，赢了随时还，一个人可以好几笔，全部留痕带时间；
3. **收台**：牌局页「正在打的台」右侧直接点「**收台**」（或进台面点「收台结算」）看汇总（台费收入 / 借出 / 已还 / 牌面还欠），谁要结账当场点「收款」，剩下的**继续挂在各自账上**，确认收台。

**人数只有 3 人 / 4 人**：一场牌就这两种，界面上没有别的档位。加人时人数会跟着走（加到第 4 个人就是 4 人台），点一下按钮就锁死、之后加人不再自动改；没记名字的人按默认台费补，人数满 4 人后再加的人（替手 / 看牌的）只记借款、台费默认 0，要收自己填一笔。台费合计随时可以手改覆盖。

**台费 / 烟钱挂账**：开台时没收上来的台费、代买烟，会自动变成该客户的欠款，欠款明细带「牌局挂账」标记能追到是哪一场；改/删这场，挂账自动同步。

**催款**：客户详情页可一键拨打电话。

**登录门禁（强制）**：必须登录才能进系统，没有跳过入口。
- **第一次打开**：直接进入「设置进入密码」引导，设 4-6 位数字并确认（可填一句密码提示），设完才进得去；中途关掉页面、重开还是回到这一步；
- **之后每次打开**：出现锁屏，输对密码才能进。**默认不记住本机**（每次都要输）；想省事可在锁屏页勾「本机记住 7 天」；
- 「我的 → 安全」里只有「修改密码」和「立即锁定」，**没有关闭密码锁的开关**——门禁关不掉；
- 连续输错 3 次会显示你设置时填的**密码提示**；输错 5 次冷却 30 秒；
- 密码经过加盐多轮哈希后存储，**不存明文**；但密码只存在本机、无法找回——忘了只能「清空数据并重置密码」重设（有备份就能恢复）。

## 口径约定

- 每位客户一个余额：**正数 = 他欠你（红色）**，**负数 = 你多收了他的（绿色）**，0 = 已结清。
- 「记欠款」= 欠款增加；「收回欠款」= 欠款减少。支持部分还款，笔笔留痕。
- 流水可随时点开修改、删除，改完余额自动重算。
- **营业额 ≠ 现金**：营业额含挂账部分，「收现」是当场实际到手的，差额就是挂账。
- **借款不是收入**：开台借给客人的钱是往来款（欠款增加），只有台费算营业收入；客人还钱是欠款减少，也不算收入。
- 挂账的烟钱是代买垫付，**不算营业额**，只进客户欠款。

**云端备份（v2.0）**：把账自动备份到**自己的服务器**，换手机、清缓存、手机丢了都不怕。
**收台对账（v2.2）**：收台时逐人确认「这台费收到没有」——默认是**待确认**（账面不会替你当成收到了），点一下=已收、再点一下=记他账上；有人没确认完，收台按钮按不动。全收到了就点「这场全都收到了」一键。挂账的自动记到客人账上，营业额照算；没确认的钱单独列着，不算收到也不算欠。
- **进入密码就是云端密码**，用户只需要记一个；首次设置进入密码时会自动连上云端并备份本机账目；
- 平时记账后 **4 秒内自动上传**，不用管；从后台切回前台也会顺手同步一次；
- **「我的 → 云端备份」**：看同步状态、立即同步、云端版本历史（可**下载** / **回滚**）、下载云端备份、重新连接；
- **两台手机用同一个密码登录，看到的是同一本账**（服务器端只有一本账）；
- **版本历史**：每次同步留一个版本（滚动保留最近 60 个 + 每天首个保留 90 天），随时能翻回旧版本，**回滚本身也能再回滚**；
- **两台设备都有改动时不会自动猜**，弹窗让用户选「用云端的 / 用本机的」，两边的旧版本都还在历史里；
- **没有后端 / 断网时完全降级**：一切照常当单机用，不报错、不阻塞，联网后自动补传；
- 部署方法见 **`deploy/Node后端部署指引.md`**（后台主用 **Node 版：零依赖，不需要 PHP，不需要数据库**）；
  PHP 版作为备选保留，见 `deploy/云端部署指引.md`——两套接口逐字段一致，前端一行都不用改。

## 数据安全（重要）

- 账目**日常存在手机浏览器本地**（`localStorage`），断网照常记账；
- 同时**自动备份到自己的服务器**（后端数据目录里的 `ledger.json` + 每次同步的历史版本；Node 版默认在 `ledger-api-node/data/`），所以：
  - 换手机 → 同一个密码登录就把账搬过去；
  - 手机上清了浏览器数据 → 用「云端备份 → 重新连接」把账拉回来；
  - 记错 / 误删 → 「云端版本历史 → 恢复」翻回那一天的版本。
- 依旧建议偶尔用「**导出备份文件**」在手机里留一份 json（换机、离线存档用）；
- ⚠️ 后端的数据目录（Node 版 `ledger-api-node/data/`、PHP 版 `api/data/`）是账本本体，**不要删**。里面的 `daily/` 可以直接下载到电脑当冷备份。

## 技术备注

- 纯原生 HTML/CSS/JS 单页应用，零依赖、零构建；PWA（manifest + service worker）支持离线与主屏幕安装。
- 牌局模型：一场牌有生命周期（open/closed），场内的借款/还款/挂账全部以流水形式存储并用场次 ID 双向关联——真相只有一份，改删场次自动同步，不会两边对不上。
- 登录门禁为**本地**门禁：SHA-256 加盐 3000 轮迭代存 localStorage（HTTP 下无 WebCrypto，故内置纯 JS 实现）；**同一个密码同时用于云端登录**，用户只需记一个。
- 云端后台有**两套等价实现**，接口、状态码、错误语义逐字段一致（同一套 116 项测试两边都跑通）：
  - **`server/node/`（Node 版，主用）**：纯 Node 内置模块（http/fs/crypto），**零依赖、无需 npm install**；
    账本以 JSON 文件存 `data/`，原子写（临时文件 + rename），单线程同步 IO 天然串行，另有跨进程锁文件兜底；
    直接访问 `/api/setup.php` 得到自检页。部署见 `deploy/Node后端部署指引.md`。
  - **`server/api/`（PHP 版，备选）**：纯 PHP（≥7.2，无框架），账本存 `api/data/`，原子写 + `flock` 排他锁。
  - 共同设计：**无数据库**；密码 PBKDF2-SHA256（2 万轮 + 随机盐，只存哈希）；登录令牌是无状态 HMAC-SHA256
    （默认 90 天，**不落盘**），改密码即轮换签名密钥、旧设备令牌全部失效；连续错密码 8 次锁 10 分钟；
    `push` 用 `baseRev` 乐观锁检测，冲突返回 409 交给前端让用户决定；自检页会**自动探测账本文件能否被外网直接下载**。
- 本地开发/测试：
  - 静态预览：`python -m http.server 8823`；
  - 带后端的完整环境：`python tools/run-cloud-tests.py [--backend=node|php] [--api-only]`
    —— 组装干净站点、起服务、跑接口断言（63 项）+ 浏览器端到端（53 项），跑完自动清理。
    Node 后端下由 `tools/dev-gateway.js` 扮演 nginx（静态文件 + `/api` 反代），保证测试跑在与生产相同的路径结构下；
  - 打包：`python tools/build-deploy.py`（产出 `deploy/ledger-site.zip` 前端包 +
    `deploy/ledger-api-node.zip` Node 后端包 + `deploy/ledger-cloud-server.zip` PHP 后端包，并同步桌面副本）。
- 图标由 `tools/make_icons.py` 生成（纯标准库，无 Pillow 依赖）。
