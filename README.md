# 往来账 · 麻将馆记账

给麻将馆老板用的客户往来账工具：**谁欠了钱、还了钱、还欠多少**，手机上点几下就记完。

## 怎么在安卓手机上用

1. 用手机 Chrome（或其他浏览器）打开应用网址；
2. 点浏览器菜单里的 **「添加到主屏幕」**；
3. 桌面上就会出现「往来账」图标，点开像普通 App 一样全屏使用，**断网也能用**。

## 功能一览

| 页面 | 干什么 |
|------|--------|
| 客户 | 应收总额 + 客户欠款列表（可搜索、按欠款/最近/姓名排序），点客户进详情，欠款分「台费 / 烟钱」小计 |
| 营收 | 每场按「人数 × 每人收费」记账（常用 10 / 20 元一键选），今日/本月营收一目了然，可手改总额（如包场优惠） |
| 流水 | 全部记录按日期倒序，可按「记欠款/收回」和「台费/烟钱/其他」双重筛选、搜客户或备注 |
| 统计 | 本月/今日营收、当前应收、场均收入、近 6 个月营收柱状图、本月往来（含烟钱合计）、欠款 TOP5 |
| 我的 | 烟品价目管理、导出备份(json)、导入备份、导出 Excel(csv)、批量导入客户名单、清空数据 |

**记一笔往来**：点右下角 <b>＋</b> → 选客户 → 选分类（台费茶水 / 代买烟 / 其他）→ 输金额 → 保存。
选「代买烟」时备注区变成烟价目表，点一下自动填金额和烟名；烟价目在「我的 → 烟品价目」里维护（默认给了几档常见价位，改成你店里常卖的名字即可）。

**记一场营收**：营收页点「记一场营收」→ 人数（默认 4，快捷 1-6）→ 每人收费（快捷 10/20/30/50）→ 总额自动算（手改则按手改的记）。

**有人当场没给钱？** 记营收时把「这场钱收了吗」切到 **「有人先记着」**：
- 每位挂账的人选客户、填台费（默认带出每人单价），还能顺手挑一包烟（从烟价目选，自动带价）；
- 保存后这部分自动变成该客户的欠款，**不用再去「记一笔」重复录**；欠款明细里带「营收挂账」标记，能追到是哪一场；
- 改/删这场营收，客户账上的挂账会自动同步；客户后来付了，正常「收欠款」即可。

**催款**：客户详情页可一键拨打电话。

## 口径约定

- 每位客户一个余额：**正数 = 他欠你（红色）**，**负数 = 你多收了他的（绿色）**，0 = 已结清。
- 「记欠款」= 欠款增加；「收回欠款」= 欠款减少。支持部分还款，笔笔留痕。
- 流水可随时点开修改、删除，改完余额自动重算。
- **营业额 ≠ 现金**：营收统计里「营业额」含挂账部分，「收现」是当场实际到手的，差额就是挂账（挂账的台费 + 挂账的烟钱分开算）。
- 挂账的烟钱是代买垫付，**不算营业额**，只进客户欠款。

## 数据安全（重要）

- 所有数据只存在 **手机的浏览器本地**，不上传任何服务器，不联网也能用。
- ⚠️ 清浏览器数据/卸载浏览器可能丢数据。**请定期在「我的」里点「导出备份文件」**，换手机时用「导入备份」恢复。
- 同一部手机上换浏览器打开 = 两份独立数据。

## 技术备注

- 纯原生 HTML/CSS/JS 单页应用，零依赖、零构建；PWA（manifest + service worker）支持离线与主屏幕安装。
- 本地开发预览：在本目录起任意静态服务器（如 `python -m http.server 8823`）后访问。
- 图标由 `tools/make_icons.py` 生成（纯标准库，无 Pillow 依赖）。
